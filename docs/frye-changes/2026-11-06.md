# Frye changes — 2026-11-06

## Summary

Both client repos moved on Nov 5 (backend PRs #251–#261, dashboard PRs #171–#178). Three things matter
for Redline. First, Engine 22 now publishes three **research-only** Nov 5 owner models (Minor W2, Minute ABC,
Subminute Nov 5 ABC). Frye's Strategies card shows them in place of the live Minute/Minor/Subminute cards,
while the canonical selection stays the same. Second, Engine 25 full-dashboard adds `headline.lastUpdatedAt`
and stops treating failed credit/rates observations as available or `+0.00%`. Third, there are two new
read routes, `/live/eod-shadow-history[/:date]`, and the `:date` variant looks broken. `server.js` did not change.

## API changes

- **New GET `/live/eod-shadow-history`** (`services/core/routes/live.js:460`). It returns `{ ok, dates: ["YYYY-MM-DD", …] }`, newest first, from the EOD branch `data/eod-shadow-history/index.json`, and is served with last-good caching.
- **New GET `/live/eod-shadow-history/:date`** (`live.js:472`) returns one immutable snapshot for a session. **Likely bug:** the date check at `live.js:474` is `/^\\d{4}-\\d{2}-\\d{2}$/`. In a regex literal that matches a literal backslash followed by `d`, so every real date (e.g. `2026-11-05`) should get `400 INVALID_SESSION_DATE`. Frye only calls the index route, so the bug doesn't show up there. Not verified against Render.
- **`GET /api/v1/engine25/full-dashboard` response changes** (`services/core/routes/engine25FullDashboard.js`):
  - `headline.lastUpdatedAt` is new. It is the composite rebuild time (`composite.generatedAtUtc || finishedAt`, line 990), or the market-health `updatedAt` on the fallback headline (line 889). It is not the request time.
  - `creditStressDetail` items (`normalizeStressItem`, from ~line 105): `available` now requires `raw.ok !== false` and a finite `value`/`close`. Momentum fields alone no longer count. When an item is unavailable, `pctChange5d/20d/50d` are `null` and `state` is `"UNAVAILABLE"`. `observationDate` also falls back to `latestDate`.
  - `buildCreditStressDetail(marketHealth, marketFeeds, macroFeeds)` (line 153): the HYG/JNK/LQD/KRE/IWM rows can now come from the daily Polygon feed. The DGS10/DGS2/T10Y2Y/T10Y3M rows can come from Engine 29's official slow context, where `observationDate` is null on purpose, or from FRED with that observation's own date.
  - Optional detail files are read with `readOptionalDetailJson` (line 86), so a partial file returns `null` instead of a 500.
- **`/engine25/refresh`** (`services/core/routes/engine25Refresh.js`) adds `mode=core`, which is POST-only and needs a cron header token. Unknown modes now return 400. This is an admin route, so Redline must keep not calling it (CLAUDE.md rule 5; handoff §6 line 236 still applies).
- No route was mounted or unmounted. `server.js` is unchanged.
