## API changes

No route was mounted, unmounted or renamed (`services/core/server.js` has no diff). The changes are to response fields only:

- **`/api/v1/engine25/*` participation diagnostics (blended participation, timeframe `eod`)**
  - `sourceSessionDate` now prefers `payload.meta.completedSessionDate` when it is a `YYYY-MM-DD` string. Otherwise it falls back to the publish-timestamp market date as before.
  - See `services/core/logic/engine25/buildBlendedParticipation.js:160-166` and `:203-207`.
  - EOD `freshnessState` is computed from that date, so a Sunday republish of Friday data is now `FRESH` instead of stale or mis-dated.
- **EOD artifact freshness:** `buildEodFreshness` uses `sectorHealth.sources.eod.completedSessionDate` (`services/core/logic/engine25/buildParticipationArtifact.js:245-248`).
- **Sector health:** `sources.eod.completedSessionDate` is a new field, `null` when not verified (`services/core/logic/engine25SectorHealth.js:408`).
- **EOD publisher:** `meta.completedSessionDate` is set only when the source's `shadowCompletedSessionDate` equals the last SPY daily bar date. Otherwise it is `null` (`scripts/make_eod.py:676-682`).
- **Engine 25 refresh (admin route, Redline never calls it)**
  - In `mode=live` with ES closed, the route no longer returns `skipped:true, reason:ES_GLOBEX_CLOSED`. It runs only `updateEngine25Participation.js` (`services/core/routes/engine25Refresh.js:110-113`, `:305`).
  - New response fields: `closedEquitySync`, `esLiveStepsSkipped`.
  - Effect for readers: the participation artifact keeps updating on weekends and holidays, but the ES, macro, Engine 29 and permission artifacts do not.
- **Engine 22 wavelength payload (inside the snapshot/wavelength data Redline already loads)**
  - `currentWavelength.degrees.micro.ownerMicroW2Nov6Research` (`buildCurrentWavelength.js:619`)
  - `currentWavelength.degrees.submicro.ownerSubmicroNov6AbcResearch` (`buildCurrentWavelength.js:575`)
  - Both models carry `selectionStatus:"RESEARCH_ONLY"`, `reviewOnly`, `noExecution`, `noPermissionCreated` and `priceBasisReconciliation:"PENDING"`, plus a `levels[]` array.
  - Each level has `status: WATCH|TOUCHED`, `touchEvidenceType` (`ES_CURRENT_PRICE` / `ES_10M_COMPLETED_OHLC`), `touchedAt` and a `touchEvidence.evidenceClass`.
  - The touches are computed in `applyOwnerPriceTouchesV1.js:777-834`.
