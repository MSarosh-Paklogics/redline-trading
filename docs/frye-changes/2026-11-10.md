## API changes

1. **New route family, owner-protected: `/api/engine22/wave-history`.** It is mounted at `services/core/server.js:168`, with preflights at `:105-106`. Handlers are in `services/core/routes/engine22WaveHistory.js`:
   - `GET /` (`:34`): `afterRevision`, `limit` → journal page.
   - `GET /nodes` (`:45`) and `GET /nodes/current` (`:54`): node revisions.
   - `GET /workbook` (`:61`): xlsx download.
   - Every path returns **401** without either a Bearer token or an `x-engine2c-access` owner key (`:16-30`).
   - The node paths only send CORS headers to `https://frye-dashboard.onrender.com` (`logic/engine22/history/nodeHistoryOwnerAccessV1.js:5,20-33`).
   - They return 503 when the durable mount isn't verified.
   - **Redline must not call these routes.** They need a secret, they are an owner-only surface, and the CORS rules block Redline's origin anyway. Add them to handoff §6 "Not for Redline".
2. **New field, public: `strategies["intraday_scalp@10m"].engine22WaveStrategy.workingWaveNodes`** in `GET /api/v1/dashboard-snapshot`. It is built at `logic/engine22/wave/buildEngine22WaveStrategy.js:2350`, using `buildEngine22WorkingWaveNodesV1.js`.
   - Top level: `schema:"engine22.workingWaveNodes.v1"`, `authority:"ENGINE22"`, `available`, `symbol:"ES"`, `readOnly`, `fingerprint` (content hash, used for change detection), `degreeOrder[7]`, `historicalAsOfSupported:false`, `ownerCountPromotion:false`, `noExecution`, `noPermissionCreated`, `noWaveTransition`.
   - `degrees.{primary…submicro}`: `{available, models[], nodes[], nodeCount, dateOnlyMarkCount, coverageStatus}`. `coverageStatus` is one of `VALIDATED_RESEARCH_NODES`, `EXACT_EVENT_TIME_MISSING`, `NO_CURRENT_CHART_NODES_BY_OWNER` or `NO_VALIDATED_CURRENT_NODES` (`:118-121`).
   - Each node (`:55-67`): `nodeId`, `waveId`, `modelVersion`, `degree`, `sourcePath`, `anchorField`, `label`, `price`, `marketAtUtc`, `ownerArizonaTime`, `sourceRevision`, `approvalStatus:"RESEARCH"`, `lifecycle:"DEVELOPING"`, `waveCompletionConfirmed:false`, **`plotAllowed:false`**, `presentationAllowed`, `sourceTimestampConflict`, `priceBasisStatus`.
   - `models[].historicalAnchors[]` holds superseded anchors with `presentationAllowed:false`.
   - Primary, Intermediate and Minor nodes come from `degreeStates.<deg>` marks (`buildSelectedDegreeNodeModelsV1.js:57`). Marks that have a date but no time are blocked, not guessed.
3. **New field, feature-gated: `strategies["intraday_scalp@10m"].engine22WaveHistory`** (`jobs/buildStrategySnapshot.js:10578-10621`). It only appears when `ENGINE22_WAVE_HISTORY_ENABLED==="true"` (ES only).
